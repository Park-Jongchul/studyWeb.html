21권 공개 본문 비교와 웹 교재 전체 점검

확인일: 2026-11-20 · 웹 교재로 돌아가기

확인 범위를 먼저 밝힙니다. 21권을 전권 완독했다는 뜻이 아닙니다. 입문서·온라인 책의 공개 본문과 출판사 샘플을 직접 확인했습니다. 출판사 미리보기는 공개된 도입 문단까지만 읽을 수 있었으며, 유료 본문은 확인했다고 세지 않았습니다. Git·DOM·후속 학습 도서는 기초 개념의 보조 비교로 구분했습니다. 모든 책이 완전 초보에게 가장 쉬운 책이라는 뜻도 아닙니다.

책 목차만으로 비교하지 않았습니다. 아래에는 실제 확인한 범위, 그 설명에서 확인한 특징, 우리 교재에 적용하거나 점검한 위치를 적었습니다. 원문·도판을 복제하지 않고 자체 설명과 예제를 작성했습니다. 구판의 개발 도구·서비스 정보는 그대로 채택하지 않았습니다.

20개 장 전체 점검

유지로 적은 장도 실행 위치·예제·학습 순서를 확인했습니다. 발견한 부족한 부분은 아래처럼 수정했습니다.

장확인·발견처리
1 설치개발 도구 역할·다운로드·설치·폴더·저장·확장자·브라우저 열기 설명 확인기존 단계·그림 유지
2 HTML태그·속성·중첩부터 링크·이미지·표·폼까지 순서 확인13개 실행 실습 유지
3 CSS태그 선택자부터 글자·여백·박스·외부 파일을 거쳐 마지막에 클래스인지 확인17개 실행 실습 및 클래스 마지막 유지
4 반응형전체 코드 앞에 배치·단위·복합 선택자 설명 부족Grid·Flex·fr·repeat·calc·clamp·rem·vw·상태 선택자 설명, 1→2→3칸 제작 순서 추가
5 첫 JS개발자 도구 안내가 첫 실행보다 앞에 있는지 확인Console·VS Code의 서로 다른 실행 경로 유지
6 변수선언·읽기·재대입·const 설명 확인기존 값 추적 예제 유지
7 자료형계산 기호·typeof 설명이 연습 지시보다 늦음기호 표·NaN 설명 추가, 백틱 예제는 선택 복습 안내
8 조건&&·||·!와 괄호의 역할을 표 한 줄로 압축참·거짓 사례 표와 괄호 설명 추가, 비교표의 예시 불일치 수정
9 함수정의·호출·인수·매개변수·반환·출력 구분 확인기존 단계별 함수 실습 유지
10 배열·반복const 반복 항목이 바뀌는 이유가 빠짐대괄호·길이·반복별 새 이름·빈 목록 설명 추가
11 객체·클래스클래스가 직접 객체보다 먼저 등장, 풀이에 코틀린 혼입직접 객체 예제 먼저, 생성 호출 new 누락과 코틀린 혼입 수정, this·생성자 안내 추가
12 DOM·함수 전달id·#·document를 연결하는 사전 설명 부족요소 찾기→변수→이벤트→화면 변경 해설, 파일은 자동 변경되지 않음 명시
13 폼event·trim·기본 제출의 동작을 더 풀어야 함7단계 흐름과 빈값·공백·Enter 점검 표 추가
14 저장JSON 변환과 실제 저장이 혼동될 여지, 로컬 서버 뒤 장 참조변환·저장 분리, ??·try/catch·사이트별 저장 설명, 현재 장 Live Server 안내로 참조 수정
15 파일·오류같은 폴더인데 study-materials/ 경로 사용상대 경로 수정, 독립 세 파일 전체 예제·Network 404 확인 추가
16 최종 프로젝트forEach·축약 객체·배열 변경이 갑자기 등장새 명령별 풀이와 읽는 순서 추가. 실제 접수·영구 저장은 없다는 기존 안내 확인
17 호스팅내 PC·원격 저장소·호스팅 구분 및 처음 한 번 설정 확인한 경로 안내 유지
18 도메인도메인 역할·등록·갱신·호스팅 중복 구입 방지 확인도메인 선택 사항과 비용 안내 유지
19 주소 연결Pages와 DNS 입력 위치·값·HTTPS 확인기존 한 번 설정 안내 유지
20 반영Commit이 공개 반영으로 오해될 수 있음저장·Stage·Commit·Push·자동 배포 범위 표, 같은 Clone 폴더/main 확인 추가
