도메인 공개 실습용 정적 웹 예제

1. 로컬에서 index.html을 열고 버튼을 누르세요.
2. GitHub 저장소 최상위에 index.html, style.css, app.js, .nojekyll을 올립니다.
3. Pages에서 main / (root)를 지정하고 공개 기본 주소를 확인합니다.
4. 내 도메인 등록과 DNS 연결은 웹 교재 18~19장을 따르세요.
5. v1을 v2로 바꿀 때 index.html의 공개 연습 v1 문구·style.css 색·app.js 버튼 문구를 수정합니다.
6. 바뀐 파일을 같은 저장소·이름·경로에 업로드하고 커밋한 다음 Pages 배포를 확인하세요.
7. 실제 도메인으로 접속해 제목·색·버튼을 확인합니다.

이 예제는 실제 예약·전송·결제 기능이 없는 공개 연습 파일입니다.
비밀번호·API 비밀 키·고객 정보는 공개 파일에 넣지 않습니다.
CNAME은 본인 도메인을 Pages에 설정할 때 생성/유지하며 예시 도메인을 복사해 만들지 마세요.
